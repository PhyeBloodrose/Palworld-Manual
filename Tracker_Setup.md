# The Tracker
The tracker for this manual is made with the Archipelago Visual Tracker which you can find from the main Archipelago Server!

Follow the guide on how to install it. Then download the .zip file from the latest release and put it in the 'visual_packs' folder.

## What is the Archipelago Visual Tracker?
Archipelago Visual Tracker is a client that runs on top of Universal Tracker. You connect to your slot the same way you would with UT, and all logic / reachability still comes from the official UT engine — nothing to reimplement per game.

What it adds is a Mapping tab: load a visual pack and see your checks on map images, with pin colors for collected, in logic, hinted, and so on.

## Why use this Tracker and not Poptracker/Universal Tracker?
The main reason I'm using this tracker to make a way to track the game is the ease of use. I've tried making a poptracker pack but I got intimidated by the scope of it.

Can't say I have meddled with the Universal Tracker Map tabs.

The Archipelago Visual Tracker map editor was so easy to use! Just make an image and add your locations to it with the click of a button! Just drag them around where you want them and done!
